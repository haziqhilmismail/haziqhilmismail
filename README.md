# Haziq Hilmi

Data engineer in Selangor, Malaysia, and a home lab hobbyist. At work I build data pipelines. At home I run a Proxmox server with 24 Docker containers, and I build small tools for the things I like: Japanese, Magic: The Gathering and Old School RuneScape.

## Projects

- **[MTG Card Scanner](https://mtg.haziqhilmi.com):** take one photo of a pile of Magic: The Gathering cards, and it names and prices each card. I use it when I sell cards at night markets.
- **[Minerr](https://github.com/haziqhilmismail/minerr):** my own Migaku, as a Chrome extension. It underlines each Japanese word by how well I know it. When I find a new word in a YouTube subtitle, I press A and it becomes an Anki card with the sentence and the audio of that line.
- **[AFK Minimize](https://github.com/haziqhilmismail/afk-minimize):** a RuneLite plugin. It minimizes the client a moment after a notification brings it to the front.
- **[Rumah Power Log](https://github.com/haziqhilmismail/my-tnb):** a dashboard for the electricity use of my house. Every 6 hours it pulls the smart-meter readings from myTNB and shows the cost, the weekday pattern and the bill history. Docker Compose, Caddy, Python.
- **[Concert Notifier](https://github.com/haziqhilmismail/concert-notifier):** it watches Google News for the artists that I follow, and Claude keeps only the concert news for Malaysia and Singapore. I get each one on Telegram.
- **[Morning Paper](https://github.com/haziqhilmismail/morning-paper):** a newspaper for my Kindle every morning. Claude picks about 10 articles from my topics, my feeds and the books I read, and KOReader syncs the EPUB over OPDS. Python, Docker, Caddy.
- **[Complainerr](https://github.com/haziqhilmismail/complainerr):** a Python CLI that files complaints on SISPAA, the Malaysian public complaint portal (JPA and MBSJ). I use it to report potholes and illegal parking to the council.
- **[tower-infra](https://github.com/haziqhilmismail/tower-infra):** the configs and scripts of my home server. A daily backup goes to Backblaze B2, and a weekly test restores a part of it and compares it byte by byte.
- **[MTG Deck Building](https://github.com/haziqhilmismail/mtg-deck-building):** a Claude Code skill for Magic: The Gathering Commander decks. It finds cuts and upgrades with prices from Card Kingdom, and it plays test games with a real shuffle.

## Tools I use

Python, SQL, Apache Airflow, Microsoft Fabric, MongoDB, FastAPI, Docker, Kubernetes, Linux, Proxmox
